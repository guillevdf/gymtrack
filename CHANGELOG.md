# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2024-12-09

### Added
- Initial release of GymTrack
- Create and manage workout routines
- Add exercises with type, sets, weight, and repetitions
- Progressive overload tracking by week
- Training stage management
- Local data persistence using SharedPreferences
- Cross-platform support (iOS and Android)
- WearOS adapted interface for smartwatches
- Home screen with routine list
- Routine creation and editing functionality
- Routine detail view with training history
- Training stage screen for tracking workouts
- Provider-based state management
- Material Design 3 UI
- Dark theme support for wearables

### Platform Support
- Android 5.0 (API 21) and above
- iOS 12.0 and above
- WearOS compatible
- WatchOS support through iOS build

### Technical Features
- Flutter 3.0+ compatibility
- JSON-based data serialization
- Immutable data models
- Form validation
- Navigation system
- Responsive UI
